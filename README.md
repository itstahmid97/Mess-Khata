# 🏠 মেস খাতা (MessKhata) - স্মার্ট ও আধুনিক মেস-মিল হিসাব সমাধান

একটি পূর্ণাঙ্গ আধুনিক ওয়েব অ্যাপ্লিকেশন যা মেসের চিরাচরিত জটিল খাতা বা এক্সেল শিটের সম্পূর্ণ বিকল্প। এটি মেস ম্যানেজার এবং সকল সদস্যদের জন্য রিয়েল-টাইম মিল রেট, বাজার খরচ, বাসা ভাড়া, বিভিন্ন ইউটিলিটি বিল এবং মাসিক ব্যালেন্স (পাওনা/বকেয়া) নির্ভুলভাবে হিসাব করে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **🔐 সুরক্ষিত এডমিন/ম্যানেজার প্যানেল:**
   - ডিফল্ট প্রাথমিক মাস্টার পাসওয়ার্ড: `@@Meal##1`
   - পাসওয়ার্ড পরিবর্তন বা রিসেট অপশন (Current Password & New Password)
   - মেম্বার যোগ, এডিট, রিমুভ এবং প্রতিটি মেম্বারের জন্য আলাদা লগইন ইউজারনেম ও পাসওয়ার্ড নির্ধারণ

2. **🍽️ তারিখ ও বার ভিত্তিক দৈনিক মিল খাতা:**
   - প্রতিটি দিনের বাংলা তারিখ ও বার (যেমন: *০৫ নভেম্বর ২০২৬, বৃহস্পতিবার*)
   - দ্রুত ১-ক্লিকে মিল পরিবর্তন: `-0.5`, `+0.5`, `1`, `2`, `3` অথবা কাস্টম সংখ্যা
   - দিনভিত্তিক ফোকাসড ভিউ এবং পুরো মাসের ১-৩১ তারিখের পূর্ণাঙ্গ শিট ভিউ

3. **🛒 বাজার খরচ ও রিয়েলটাইম মিল রেট:**
   - বাজারকারীর নাম, তারিখ, বাজারের ফর্দ এবং টাকার পরিমাণ
   - **মিল রেটের সূত্র:** `বর্তমান মিল রেট = মোট বাজার খরচ ÷ মোট মিল সংখ্যা`
   - সদস্যের মিল খরচ = `ব্যক্তিগত মোট মিল × মিল রেট`

4. **🏠 বাসা ভাড়া ও ইউটিলিটি বিলের ডায়নামিক খাত (Segments):**
   - বাসা ভাড়া, ওয়াইফাই বিল, গ্যাস সিলিন্ডার, বিদ্যুৎ বিল, খালা/বুয়া বিল, ময়লা বিল ইত্যাদি
   - এডমিন প্যানেল থেকে যেকোনো নতুন খাত যুক্ত বা বাদ দেওয়ার সুবিধা
   - জনপ্রতি খরচ সক্রিয় সদস্যদের মাঝে স্বয়ংক্রিয় সমান বণ্টন

5. **💵 টাকা জমা (Deposit) ট্র্যাকিং:**
   - মেম্বারদের অগ্রিম টাকা জমার তারিখ, মাধ্যম (ক্যাশ, বিকাশ, নগদ, ব্যাংক) ও নোট

6. **📊 সদস্যভিত্তিক সমাপনী হিসাব (Final Balance):**
   - **পাবে (সবুজ):** মেম্বার বেশি টাকা জমা রেখেছেন, মেস থেকে ফেরত পাবেন
   - **দিতে হবে (লাল):** মেম্বারের বকেয়া টাকা, মেস ম্যানেজারের কাছে জমা দিতে হবে

7. **📁 মাস সমাপনী, অটো-রিসেট ও আর্কাইভ:**
   - প্রতি মাস শেষে ১-ক্লিকে চলতি মাস ক্লোজ ও আর্কাইভে সংরক্ষণ
   - নতুন মাসের জন্য মিল ও বাজার স্বয়ংক্রিয় রিসেট
   - পূর্ববর্তী মাসের পাওনা/বকেয়া ব্যালেন্স নতুন মাসে সমর্পণ (Carry-forward) করার অপশন

8. **🖨️ ১-ক্লিকে প্রফেশনাল PDF রিপোর্ট ডাউনলোড ও প্রিন্ট:**
   - বাংলা ফন্ট, মেসের নাম, মেম্বারদের টেবিল, বাজার তালিকা ও ম্যানেজারের স্বাক্ষরযুক্ত ফরম্যাট

9. **🛡️ ব্রাউজার ক্র্যাশ প্রটেকশন ও লোকাল ব্যাকআপ:**
   - ডাটাবেজ ডাউন বা নেটওয়ার্ক বিচ্ছিন্ন থাকলেও ব্রাউজারে রিয়েলটাইম সেভ
   - ১-ক্লিকে সমস্ত ডাটা `.json` ব্যাকআপ ফাইল ডাউনলোড ও যেকোনো সময় রিস্টোর

10. **🏢 মাল্টি-মেস সুবিধা (Multi-Tenant):**
    - যে কেউ নিজস্ব মেস তৈরি করে আলাদা এডমিন প্যানেল পরিচালনা করতে পারে

11. **☁️ Supabase ডাটাবেজ রেডি:**
    - `supabase_schema.sql` ফাইল সহ প্রস্তুত ক্লাউড ডাটাবেজ স্কিমা

## 🚀 কীভাবে চালাবেন (Quick Start)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে যান: `http://localhost:3000`

### ৩. প্রোডাকশন বিল্ড ও রান:
```bash
npm run build
npm start
```

## 🗄️ Supabase ডাটাবেজ সেটআপ (ঐচ্ছিক)

১. [Supabase](https://supabase.com)-এ একটি প্রজেক্ট তৈরি করুন।
২. Supabase ড্যাশবোর্ডের **SQL Editor**-এ গিয়ে প্রজেক্টে থাকা `supabase_schema.sql` স্ক্রিপ্টটি রান করুন।
৩. `.env.local` ফাইল তৈরি করে আপনার Supabase ক্রেডেনশিয়াল যোগ করুন:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
*(নোট: Supabase কনফিগার না করলেও সম্পূর্ণ সিস্টেমটি ব্রাউজার লোকাল স্টোরেজে শতভাগ স্বয়ংক্রিয়ভাবে চলবে!)*
